## Fine-Tuningっていつ使うの？ 〜小さなLLMをモデルルーターにして分かったこと〜

### What

```
「Fine-Tuningって、結局いつ使えばいいの？」
そんな疑問から、小さなLLMをモデルルーターとしてFine-Tuningする検証を始めてみました。
Promptを書けばいいのか、RAGを使えばいいのか、それともFine-Tuningが必要なのか――。
AIを使っていると、一度は悩むこの「使い分け」。
このセッションでは、実際に小さなLLMをFine-Tuningしてモデルルーターとして動かす実験を通して、Prompt・RAG・Fine-Tuningの違いや、それぞれがどんな場面で活きるのかを初学者向けに紹介します。

Fine-Tuningってそもそも何？
PromptやRAGとは何が違う？
なぜ小さなLLMをモデルルーターにしたのか？
実際にFine-Tuningしてみて何が分かった？

キーワードは、「Fine-Tuningはいつ使うのか」。
実際に手を動かして試してみたからこそ分かった、Fine-Tuningの「できること」と「できないこと」。
明日からAIを使うときの、「Prompt？ RAG？ それともFine-Tuning？」を判断するヒントが詰まったセッションです。
```
